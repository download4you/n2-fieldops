# Routing

| Signal | Skill |
|---|---|
| `+++` syntax or decorator state | `fieldops-prompt-decorators` |
| Authorized CTF evidence/provenance | `fieldops-ctf-operator` |
| Repository implementation or diagnosis | `fieldops-engineering` |
| Persian/Unicode PowerShell | `fieldops-powershell-utf8` |
| Prompt improvement or modularization | `fieldops-prompt-refiner` |
| Externally verifiable question, comparison, or uncertain claim | `fieldops-research` |

For CTFs, combine the evidence skill with a compatible installed category specialist when one is available. If none is installed, classify the domain with the bundled references and proceed using available tools. Use an installed write-up skill for final reporting when useful, but never make completion depend on an optional external skill.

For an unfamiliar task with no exact route:

1. Use `fieldops-research` to establish facts, terminology, and available evidence.
2. Decompose the task into investigation, implementation, verification, and reporting.
3. Route only the workstreams that match a specialist skill.
4. Execute unmatched work directly with the current runtime tools.
5. Preserve one shared ledger so findings and assumptions survive handoffs.

Do not answer with a routing-only response when useful work can begin immediately.
