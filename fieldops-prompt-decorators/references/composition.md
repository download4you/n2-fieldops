# Composition

Apply precedence in this order:

1. Clear, scope, and state inspection.
2. Current explicit task constraints.
3. Output or export container.
4. Content transformations and structures.
5. Tone and candor.

- `OutputFormat` is the final container; encode other required sections as fields.
- `FactCheck + CiteSources`: share verification; mark unavailable evidence; never invent.
- `Interactive + Socratic`: use one question round and the tighter valid limit.
- `Interactive/Socratic + strict format`: questions may use the format when practical;
  resume the requested final format after answers.
- `Brainstorm + Critique`: generate first, evaluate in a separate section or phase.
- `Rewrite + Refine`: rewrite first, then iterate.
- `Planning + StepByStep`: plan briefly, then execute without duplicating the plan.
- `Tone + Candor`: tone controls style; candor controls directness.
- `Export/Dump`: export only visible conversation content and active decorator state;
  never imply access to hidden reasoning or unavailable messages.
- `N2`/`Storm`: expand the meta-decorator stack first (see
  `references/meta-decorators.md`); explicit tokens in the same message then overlay
  or adjust that stack.
- Mandatory platform output, channels, permissions, tools, and skill workflows win.
