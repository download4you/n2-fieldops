# n2-fieldops for Claude Code

This generated plugin contains the 17 canonical n2-fieldops skills for research,
engineering, Prompt Decorators, PowerShell UTF-8, and authorized CTF work.

Run it from the extracted directory:

```bash
claude --plugin-dir ./n2-fieldops-claude-plugin
```

Claude Code does not load a plugin-root `CLAUDE.md` as project memory. Review
`docs/CLAUDE_PROFILE.md` and copy it to the target project as `CLAUDE.md` only when
you want the optional always-on profile.

The prompts are model-neutral and support the current Claude Opus family. The same
canonical skills also support Codex GPT/Codex through the repository root or CC
Switch.

source revision.
