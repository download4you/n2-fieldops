# Domain First Pass

- Web/API: entry HTML, routes, middleware, sessions, storage, uploads, workers, request order.
- Backend/async: entrypoints, handlers, queues, cron, retries, state transitions.
- Reverse/malware/DFIR: headers, imports, strings, sections, config, persistence, embedded layers, PCAP/log correlation.
- Native/pwn: format, mitigations, runtime, primitive, controlled bytes, leak, target, offsets, framing.
- Crypto/stego/mobile: transform chain, parameters, metadata, channels, signing, storage, hooks, trust boundaries.
- Identity/Windows/cloud: token/ticket flow, credential usability, pivot chain, runtime differences, deployment truth, provenance.
