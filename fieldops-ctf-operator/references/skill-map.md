# CTF skill map

Route by the current decisive blocker, not the challenge label. Pivot without restarting the evidence ledger.

| Evidence or decisive task | Primary skill | Common pivot |
|---|---|---|
| HTTP, API, auth, templates, browser state | `fieldops-ctf-web` | crypto, reverse, forensics |
| Memory corruption, ROP, heap, exploit service | `fieldops-ctf-pwn` | reverse, crypto |
| Cipher, signature, PRNG, number theory | `fieldops-ctf-crypto` | misc, pwn |
| Understand binary, APK, WASM, VM, firmware | `fieldops-ctf-reverse` | pwn, malware |
| PCAP, disk, memory, logs, stego, signals | `fieldops-ctf-forensics` | malware, crypto, OSINT |
| C2, persistence, malicious package, config | `fieldops-ctf-malware` | reverse, forensics |
| Public-source identity, location, DNS | `fieldops-ctf-osint` | forensics, misc |
| Models, checkpoints, prompt attacks, LoRA | `fieldops-ctf-ai-ml` | misc, reverse |
| Jail, encoding, SDR, esoteric, hybrid puzzle | `fieldops-ctf-misc` | whichever evidence indicates |
| Final reproducible handoff | `fieldops-ctf-writeup` | operator for disputed claims |
