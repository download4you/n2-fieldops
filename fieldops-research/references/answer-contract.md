# Answer Contract

- Start with the conclusion or recommendation.
- Distinguish fact, inference, calculation, and judgment.
- Surface only evidence that changes confidence or action.
- Include dates or versions for time-sensitive claims.
- State uncertainty precisely, not as a generic disclaimer.
- Give a concrete next step, command, decision rule, or verification method.
- Never claim a source was checked, a command was run, or a result was reproduced when
  it was not.
