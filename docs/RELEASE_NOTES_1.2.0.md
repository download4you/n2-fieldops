# n2-fieldops 1.2.0

Feature release: first-class Kimi runtime support.

## New

- `KIMI.md` at the repository root is the durable Kimi profile: the same skill-based,
  token-optimized, uncensored runtime as the Codex `AGENTS.md`, carrying the KIMI
  CODE identity, Persian-default language, Scope and Cooperation, the 11-step
  reverse-engineering/malware block, and decorator runtime awareness that reads the
  `fieldops-prompt-decorators` skill (including the `+++N2` and `+++Storm`
  meta-decorators) on any decorator signal.
- Docs and manifests now describe the multi-runtime layout (Claude Code, Codex,
  Kimi, CC Switch).

## Compatibility

The canonical repository remains one root-level tree with exactly 17 `SKILL.md`
directories. Install from CC Switch with:

```text
Repository URL: https://github.com/download4you/n2-fieldops
Branch: main
```

For an always-on Kimi profile, copy `KIMI.md` as the Kimi CLI system prompt and
restart the CLI.
